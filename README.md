A simple Telegram bot that forwards new messages from one Telegram chat/channel to another.## Files- `main.py` — main bot application- `requirements.txt` — Python dependency- `.gitignore` — prevents secrets such as `.env` from being committed- `README.md` — this setup guide## 1. Create the Telegram bot1. Open Telegram and search for **@BotFather**.2. Use `/newbot` to create a bot.3. Copy the bot token.4. Keep the token private. Do not put it directly into `main.py` or GitHub.## 2. Add the bot to your chatsThe bot needs access to the source chat and permission to send messages to the destination chat.For channels/groups, add the bot as an administrator with the permissions required to read messages and send/forward messages.## 3. Environment variablesSet these variables in Railway (or your hosting provider):```textBOT_TOKEN=your_bot_tokenSOURCE_CHAT_ID=your_source_chat_idTARGET_CHAT_ID=your_target_chat_id```Do not commit these values to GitHub.## 4. Install locally```bashpip install -r requirements.txtpython main.py```## 5. Deploy on Railway1. Push all project files to GitHub.2. Create a new Railway project.3. Deploy the GitHub repository.4. Open **Variables** in Railway.5. Add:   - `BOT_TOKEN`   - `SOURCE_CHAT_ID`   - `TARGET_CHAT_ID`6. Deploy/redeploy the service.Check the Railway logs for errors.## ImportantOnly forward content from chats you are authorized to access and redistribute. Respect Telegram's terms, privacy, copyright, and the rules of the source and destination communities.Never share your bot token publicly. If it is exposed, revoke/regenerate it with BotFather.
